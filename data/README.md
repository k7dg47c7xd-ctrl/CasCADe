# Data directory conventions

This directory (and `ablation/splits/` etc.) holds experimental data and is **not part of the repository by default**.

## Sources

- Underlying geometry and topology: the public DeepCAD dataset. Obtain it from its official repository and comply with its license terms.
- Natural-language descriptions: generated by `scripts/pre_finetune/generate_description_qwen.py` (local model or API); `scripts/pre_finetune/llm-selection/chat_qwen/` provides the batch chat and rating tooling used during base-model screening.
- Training set `configs/cad_train.json`: generated by `scripts/make_train_json.py`.

## Expected directory layout

```
data/
├── prompt_data/<uid>/<uid>_description.txt + <uid>_lite.json (+ multi-view png)
├── train_data/<uid>/...
├── verify_data/<uid>/...
├── simple/  complex/            # difficulty splits used by llm-selection
└── ...
```

## Notes

- `*_lite.json` is the hierarchical CAD-JSON ground truth (DeepCAD-converted format).
- Before redistributing derived data, confirm that the original DeepCAD license permits redistribution; if this cannot be confirmed, ship only the generation scripts.
