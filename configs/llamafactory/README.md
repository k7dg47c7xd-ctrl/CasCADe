# LLaMA-Factory dataset registration

`dataset_info.json` is a locally modified copy extracted from `third_party/LLaMA-Factory/data/dataset_info.json`; it contains this project's `cad_train` dataset registration entry.

Usage (point `--dataset_dir` at this directory when training):

```bash
cp configs/cad_train.json configs/llamafactory/cad_train.json   # generated by make_train_json.py
llamafactory-cli train configs/train_lora_custom/qwen3_6_27b_lora_sft.yaml     --dataset_dir configs/llamafactory
```

If you use the vendored checkout (`third_party/LLaMA-Factory`) without changing its default `dataset_dir`, merge this directory's `dataset_info.json` into `third_party/LLaMA-Factory/data/dataset_info.json`.
